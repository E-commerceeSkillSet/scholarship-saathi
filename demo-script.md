# Demo script — 30 to 60 seconds

**0:00 — Problem (5s)**
"Har saal hazaron students scholarship miss kar dete hain — criteria samajh hi
nahi aata. Scholarship Saathi ye masla hal karta hai."

**0:05 — Paste (10s)**
Screen par student profile text aur scheme criteria text dikhao. Ek tap par
"Sister — FSc 85%" sample dabao — Matric 85%, FSc 85%, BS Cyber Security,
public university, domicile Punjab khud bhar jata hai. Weighted merit 85%
screen par nazar aata hai.

**0:15 — Check (10s)**
"Check Karo" dabao. Teen cards aate hain — Honhaar, HEC Need-Based, PEEF.
Honhaar par NEEDS CHECK ka stamp dikhao: marks wala rule PASS hai, lekin
income, discipline list aur enrolment abhi maloom nahi — app jhooti tasalli
nahi deta.

**0:25 — Evidence (15s)**
Kisi ek rule par zoom karo: pass/fail, probability, aur asal text se quote
ki hui evidence. Phir "Fails marks test" sample dabao — wahan LIKELY NOT
aata hai, wajah bhi saath likhi hai.

**0:40 — Clocked + honesty (15s)**
Batao: andar Clocked ke chaar endpoints chalte hain — PII pehle personal
data replace karta hai, Extract fields nikalta hai, Decide har rule par
probability deta hai, Grounding jawab ko documents se verify karta hai.
Aakhir mein honesty line: "Ye sirf check hai — apply karne se pehle official
portal par zaroor confirm karein."

**0:55 — End (5s)**
Fixtures mode dikhao: "Bina key ke bhi judge poora demo dekh sakta hai."
